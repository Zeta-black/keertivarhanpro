# Data

`raw/QA-PBP-RL-Nexus` is the shallow-cloned public source for the default real
Potts-energy run. `processed/real_aggregated_potts_model.npz` records the six-
class aggregation, and the corresponding score cache contains every valid 8-mer.
`raw/proxy_scoring_model.npz` is an optional explicitly labelled fallback.
